================================================================================
Livora 셀러 PC 설정 안내
사이트만으로는 안 되는 기능을, 판매자 컴퓨터에서 해결하는 방법입니다.
================================================================================

■ 한 줄 요약

  주문 수집·엑셀·정산서·라벨 인쇄 창  →  인터넷 사이트만으로 됩니다.
  화면 캡처·파일 폴더 바로 열기      →  셀러 PC에서 Livora를 켜 두어야 합니다.
  TSC DA220 라벨 바로 출력           →  윈도우 프린터 설정 + 크롬 인쇄 설정이 필요합니다.


--------------------------------------------------------------------------------
1. 왜 사이트만으로는 안 되나
--------------------------------------------------------------------------------

  Livora 사이트가 클라우드(Render 등)에 있으면, 프로그램은 "인터넷 서버"에서
  돌아갑니다. 서버는 셀러 자리의 모니터·프린터·폴더를 볼 수 없습니다.

  그래서 아래 네 가지는 웹 페이지만으로는 원본 PC 프로그램과 같아질 수 없습니다.

  ① 셀러 PC에 떠 있는 틱톡/유튜브 창 화면 캡처
  ② 탐색기에서 엑셀·정산서·스크린샷 폴더 열기
  ③ TSC DA220에 확인 창 없이 라벨 바로 출력
  ④ 이 PC에서만 로그인 (원본의 PC 고정)

  아래는 각각 셀러 PC에서 할 수 있는 해결 방법입니다.


--------------------------------------------------------------------------------
2. 화면 캡처 (가장 중요)
--------------------------------------------------------------------------------

  [원인]
  클라우드 사이트에서 "화면캡처 ON"을 켜도, 찍히는 것은 서버 컴퓨터입니다.
  셀러 모니터의 틱톡·유튜브 창은 찍히지 않습니다.

  [해결] 방송하는 그 PC에서 Livora를 실행합니다.

  준비
    1) https://nodejs.org 에서 LTS 버전을 설치합니다. (설치 후 PC 재시작)
    2) 관리자에게 받은 Livora 폴더를 이 PC에 복사합니다.
       예) C:\Livora
    3) 그 폴더에서 명령 창을 열고 한 번만 입력합니다.
         npm install
    4) 방송을 켤 때마다 같은 폴더에서
         npm start
    5) 크롬에서 http://localhost:4173 을 엽니다. (받은 아이디로 로그인)

  방송 중
    - 틱톡 라이브 창, 유튜브 라이브 창을 이 PC에 띄워 둡니다.
    - Livora에서 화면캡처를 ON 으로 둡니다.
    - 상품을 올리기 전에 F2 또는 "F2 캡처"를 누르면 지금 화면이 저장됩니다.
    - 주문이 들어오면 그때그때 화면이 저장됩니다.

  확인
    - 엑셀·정산서 메뉴의 "화면 캡처 보기"에 사진이 쌓이면 성공입니다.


--------------------------------------------------------------------------------
3. 라벨 프린터 (TSC DA220 / 50×40mm)
--------------------------------------------------------------------------------

  [원인]
  사이트는 셀러 옆 프린터 선에 직접 연결할 수 없습니다.
  대신 브라우저 인쇄 창으로 같은 크기 라벨을 찍습니다.

  [윈도우에서 할 일]
    1) TSC 홈페이지에서 DA220 드라이버를 이 PC에 설치합니다.
    2) 테스트 페이지가 나오면 프린터가 잡힌 것입니다.
    3) Windows 설정 → 블루투스 및 장치 → 프린터 및 스캐너 → TSC DA220
    4) "인쇄 기본 설정"에서 용지 크기를 50mm × 40mm 로 맞춥니다.
    5) TSC DA220을 "기본 프린터"로 지정합니다.
    6) 여백은 모두 0, 방향은 가로/세로 중 라벨이 바르게 나오는 쪽으로 둡니다.

  [Livora에서 할 일]
    1) 주문 수집 화면에서 "라벨"을 켜서 "라벨 ON"이 되게 합니다.
    2) 테스트 주문을 한 건 넣거나, 주문 옆 "라벨" 버튼을 누릅니다.
    3) 인쇄 창이 뜨면
         프린터: TSC DA220
         용지: 50mm × 40mm (또는 사용자 지정)
         여백: 없음
         머리글/바닥글: 없음
         배경 그래픽: 끄기
    4) "이 설정을 기본값으로 저장"이 있으면 저장합니다.
    5) 수량 1~10개만 자동으로 장수가 나갑니다. 11개 이상은 검수대기입니다.

  [인쇄 창을 생략하고 싶을 때]  (선택)
    크롬 바로가기 아이콘 → 마우스 오른쪽 → 속성 → 대상 끝에 한 칸 띄고 추가:

      --kiosk-printing --app=http://localhost:4173

    예)
      "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app=http://localhost:4173

    이렇게 열면 인쇄가 기본 프린터로 바로 나갑니다.
    반드시 기본 프린터가 DA220이고 용지가 50×40mm여야 합니다.
    클라우드 사이트 주소를 쓰는 경우 --app= 뒤에 그 주소를 넣습니다.


--------------------------------------------------------------------------------
4. 엑셀·정산서·스크린샷 폴더
--------------------------------------------------------------------------------

  [원인]
  브라우저는 탐색기로 폴더를 열어 줄 수 없습니다. 파일 받기는 됩니다.

  [사이트만 쓸 때]
    1) 바탕화면에 "Livora자료" 폴더를 만듭니다.
    2) Livora → 엑셀·정산서 에서
         주문 엑셀 / 채팅 엑셀 / 정산서 만들기 / 화면 캡처 보기
    3) 받은 파일을 "Livora자료"에 저장합니다.
    4) 그 폴더를 작업 표시줄이나 바탕화면에 고정해 두면
       원본의 "폴더 열기"와 비슷하게 씁니다.

  [이 PC에서 npm start 로 켤 때]
    파일은 Livora 폴더 안에 쌓입니다.

      엑셀     C:\Livora\data\exports
      정산서   C:\Livora\data\invoices
      캡처     C:\Livora\data\shots

    각 폴더를 마우스 오른쪽 → 바로 가기 만들기 → 바탕화면에 두면
    원본처럼 폴더를 바로 열 수 있습니다.


--------------------------------------------------------------------------------
5. PC 1대만 로그인
--------------------------------------------------------------------------------

  [원인]
  사이트는 폰·다른 PC에서도 들어가게 만든 제품입니다.
  원본처럼 "이 컴퓨터만" 강제로 묶는 기능은 넣지 않았습니다.

  [셀러가 지킬 일]
    - 아이디·비밀번호를 다른 사람과 공유하지 않습니다.
    - "로그인 유지"는 본인이 쓰는 PC·폰에서만 체크합니다.
    - 카페·다른 사람 PC에서는 쓰고 반드시 로그아웃합니다.
    - 비밀번호가 새어 나갔으면 관리자에게 바꿔 달라고 합니다.


--------------------------------------------------------------------------------
6. 추천 운영 방법
--------------------------------------------------------------------------------

  A. 사무실 고정 PC에서 방송하는 경우  (원본과 가장 비슷)
     - 그 PC에 Node.js + Livora 설치
     - 매번 npm start 후 http://localhost:4173
     - 틱톡/유튜브 창을 같은 PC에 띄움
     - 화면캡처 ON, 라벨 ON
     - DA220을 기본 프린터로

  B. 클라우드 사이트만 쓰는 경우
     - 주문 수집, 엑셀, 정산서, 검수대기는 그대로 됩니다.
     - 화면 캡처는 쓰지 마세요. (서버 화면이 찍힙니다)
     - 라벨은 인쇄 창에서 DA220을 고르면 됩니다.
     - 파일은 엑셀·정산서 메뉴에서 받아 저장합니다.


--------------------------------------------------------------------------------
7. 방송 전 체크리스트
--------------------------------------------------------------------------------

  [ ] Node.js LTS 설치됨 (로컬 실행할 때)
  [ ] Livora 폴더에서 npm start 가 되고, 크롬에서 로그인됨
  [ ] 틱톡·유튜브 라이브 창이 이 PC에 켜져 있음
  [ ] 화면캡처 ON  (로컬 실행일 때만)
  [ ] F2 한 번 눌러 캡처가 저장되는지 확인
  [ ] TSC DA220 전원 ON, 용지 50×40mm, 기본 프린터
  [ ] Livora 라벨 ON
  [ ] 테스트 라벨 1장 출력
  [ ] 엑셀·정산서 받기가 되는지 확인


--------------------------------------------------------------------------------
8. 안 되면
--------------------------------------------------------------------------------

  캡처가 안 됨
    → 클라우드 주소(render 등)로 들어간 것은 아닌지 확인합니다.
       주소가 localhost:4173 이어야 이 PC 화면이 찍힙니다.

  라벨이 큰 종이로 나옴
    → 윈도우 프린터 기본 용지와 크롬 인쇄 용지를 둘 다 50×40mm로 맞춥니다.

  라벨이 안 나옴
    → 라벨 버튼이 ON 인지, 수량이 1~10인지, DA220이 기본 프린터인지 확인합니다.

  엑셀을 어디에 받았는지 모름
    → 크롬 오른쪽 위 다운로드(화살표) 또는 바탕화면 Livora자료 폴더를 봅니다.

  npm start 가 안 됨
    → 관리자에게 Livora 폴더와 Node.js 설치를 다시 요청합니다.
